# 🌱 AgriLease – Agricultural Land Management System

AgriLease is a DBMS-based web application designed to simplify and manage agricultural land-related activities. The system provides a platform for managing crop recommendations, agricultural resources, market trends, pest alerts, and other farming-related information.

## 📌 Features

* 🌾 Crop Recommendation System
* 🌱 Urban Gardening Support
* 🧪 Fertilizer Information
* 💧 Water Management
* 📈 Market Trends
* 🐛 Pest Alerts
* 👤 User Registration and Login
* 🗄️ Database-driven data management
* 🤖 ML-based crop recommendation models

## 🛠️ Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Python
* Flask

### Database

* MongoDB

### Machine Learning

* Python
* Scikit-learn
* Trained ML models for crop/plant recommendations

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Shubhashri24/AgriLease.git
cd AgriLease
```

### 2. Create a virtual environment

```bash
python -m venv agri_venv
```

### 3. Activate the virtual environment

**Windows:**

```bash
agri_venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r backend/requirements.txt
```

### 5. Run the application

```bash
python backend/app.py
```

Then open the application in your browser.
